# 🧩 Sudoku Solver

A modern and interactive **Sudoku Solver** built with **Python (Flask), HTML, CSS, and JavaScript**. This application uses the **Backtracking Algorithm** to solve Sudoku puzzles quickly while providing a clean and responsive user interface.

## 🧠 Algorithm Used

This project uses the **Backtracking Algorithm**, a recursive technique that:

- Finds an empty cell
- Tries numbers from 1 to 9
- Checks Sudoku constraints
- Backtracks when a conflict occurs
- Continues until the puzzle is solved
